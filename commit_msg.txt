Add giftplace and giftreport console hooks for the gift layer

The gift layer and the duplicate-gift fix both needed a way to be checked on
hardware. giftreport counts the objects actually on screen and whether the
placement preview is hidden, which is the direct proof that the duplicate is
gone. giftplace drives the real commit path so the layer commit and the preview
teardown are exercised rather than simulated.

layer_children=1 preview_hidden=1, giftlayer 0 -> 3 of 4 accepted and 99
rejected, build exit 0 with zero main warnings, flash exit 0 with Hash of data
verified, native suite 49/3 (documented baseline), soak PASS with 0 faults,
