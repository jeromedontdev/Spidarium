# v1.1.27 - On-screen furniture editing and the feature guide

## Arrange the enclosure without leaving it

- Hold a placed decoration or gift to edit directly on the game screen.
- Slide its artwork preview, then press Done. Releasing does not place it.
- Put Away, Done and Cancel stay over the enclosure; decor also has Blocking.
  No item submenu or Back-to-Settings route is involved.
- Done applies position and blocking together. Cancel discards both edits.
  Moving is free and preserves gift variants; Put Away retains ownership.
- New placements use the same draggable preview. Purchased decor stays owned
  when placement is cancelled. Save format and approved spider art are unchanged.

## Help, progression and controls

- Seventeen matching feature-guide topics on the website, browser and device.
  In-game Help is directly in Menu, not duplicated in Settings or About.
- Twenty reachable achievements show goals and grant 15 XP plus 20 Silk once.
  Existing earned badges are not repaid. First Molt completes its animation
  and returns to care instead of remaining stuck.
- Moonlit Hollow uses low plucks; Rainy Canopy has fast mallet arpeggios.
  Menu taps use a quieter pitched cue. The audio worker has measured refill
  diagnostics and priority above the display adapter.
- Unaffordable shop tiles are greyed out, treat purchases preserve their page,
  Borders opens correctly, icons are centered and settings use distinct art.
- Slider grab targets are inset/enlarged. WiFi focuses on network management;
  Firmware Update is under About. The flasher shows concise verification
  status without listing firmware filenames and hashes.
- Documentation and current public branding consistently describe Spidarium.

## Updating

Use the website's save-preserving USB updater and export a backup first.
The firmware checks GitHub's latest stable release and verifies size/hash,
project/version and matching artwork. A full hosted OTA download/reboot remains
unproven on the current hardware link; discovery or a safe failed transfer is
not OTA installation success. The release includes the full USB image set and
the application/OTA manifest. NVS is excluded.

## Verification

The release is validated with the build/flash wrappers, browser and host suites,
native injected pointer actions, render/radio allocation loops and a clean-boot
soak. Exact final evidence is recorded in [PROGRESS.md](../PROGRESS.md).
Physical finger feel and subjective speaker quality still require personal
acceptance; automated input and refill timing do not substitute for them.
